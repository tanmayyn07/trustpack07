TRUSTPACK FINAL WEBSITE

Files:
- index.html — complete browser-based website with OCR and working example
- vercel.json — Vercel configuration

GitHub:
1. Create a new repository.
2. Extract this ZIP.
3. Upload index.html and vercel.json to the repository root.
4. Commit the changes.
5. Import the GitHub repository into Vercel.
6. Deploy.

No Python backend is required for this version.
